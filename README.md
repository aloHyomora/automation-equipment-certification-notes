# 자동화설비산업기사 필기 공부 노트

자동화설비산업기사 필기 시험 준비용 Obsidian 볼트입니다.
GitHub(private) 저장소와 Obsidian Git 플러그인으로 동기화합니다.

## 자료 출처

이 볼트의 내용은 **오직 아래 세 가지를 기반으로만** 구성합니다.

1. **Study 자료**: 수험 교재(『2025 시대에듀 Win-Q 자동화설비산업기사 필기 단기합격』)의 핵심 키워드와 개념. 기출 내용이 반영된 핵심 자료로 참조합니다.
2. **웹 검색**: 큐넷(q-net.or.kr) 출제기준 등 공개 자료
3. **전공 지식**

교재의 키워드와 개념은 참조하되, 모든 노트는 원문을 옮기지 않고 내 말로 다시 정리합니다.

## 폴더 구조

| 폴더 | 용도 |
| --- | --- |
| `00_Inbox/` | 빠른 메모 |

| `10_자동제어/` | 1과목 |
| `20_기계요소설계/` | 2과목 |
| `30_공유압/` | 3과목 |

과목 구성은 큐넷 출제기준(2027.1.1 ~ 2030.12.31)을 따릅니다. → [출제기준 요약](01_시험안내/출제기준_2027-2030.md)

## 볼트 사용 규칙

- **이미지**: JPG/WebP로 줄여서 `attachments/`에 넣습니다. 1장당 1MB 이하를 권장합니다.
- **저작권**: 교재 원문 복사나 페이지 캡처는 금지합니다. 내 말로 요약만 합니다.
- **다이어그램**: 가능하면 Mermaid로 그립니다.
- **링크**: 표준 Markdown 링크(상대 경로)를 씁니다. 그래야 GitHub 웹에서도 링크와 이미지가 보입니다.
- **새 단원노트**: `templates/단원노트.md`로 만듭니다.
- **주제 태그**: `tags`의 첫 항목에 `주제/과목/세부주제`를 넣습니다. 그래프 뷰 색과 태그 색이 이 태그로 정해집니다.
  - 자동제어(파랑): `제어이론` `PLC` `HMI` `전기전자` `센서` `모터`
  - 기계요소설계(초록): `기초와_재료` `체결요소` `운동요소` `도면과_공차`
  - 공유압(주황): `공통` `공압` `유압`

## 처음 설정하기

1. Obsidian에서 **폴더를 보관함으로 열기**로 이 저장소 폴더를 엽니다.
2. 설정 > 커뮤니티 플러그인에서 **Obsidian Git**을 설치하고 활성화합니다.
3. (선택) 설정 > 코어 플러그인 > 템플릿에서 템플릿 폴더를 `templates`로 지정합니다.
