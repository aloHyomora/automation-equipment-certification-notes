# 학습 대시보드

> [!tip] 출퇴근 5분 학습
> 왼쪽 세로 아이콘에서 **Task Genius**를 열고, 그 화면 안의 왼쪽 메뉴에서 **Today**를 선택하세요.
> **출근 미니 강의 읽기(5분)**와 **퇴근 미니 강의 읽기(5분)**를 읽은 뒤 각각 왼쪽 체크박스를 누릅니다.
> [미니 강의 체크리스트 바로 열기](단원%20진도.md#출퇴근%20미니%20강의)

## Task Genius 화면 열고 고정하기

1. **Obsidian 창 맨 왼쪽 세로줄**에서 마우스를 아이콘 위에 올려 **Open Task Genius view**라고 뜨는 아이콘을 클릭합니다. 아이콘이 안 보이면 **Ctrl+P**를 눌러 검색창에 **Open Task Genius view**를 입력하고 **Enter**를 누르세요.
2. 가운데 열린 **Task Genius 탭** 안에서 왼쪽 메뉴의 **Today**를 클릭합니다. 오늘 날짜의 출근·퇴근 미니 강의와 본 학습을 확인할 수 있습니다.
3. 밀린 목록을 볼 때만 같은 메뉴의 **Forecast**를 클릭합니다. **Past Due**는 밀린 항목, **Today**는 오늘 항목입니다.
4. 화면 위쪽의 **Task Genius 탭 제목**을 우클릭해 **고정(Pin)**을 누릅니다. 대시보드도 계속 열어 두려면 **학습 대시보드** 탭 제목을 같은 방식으로 고정하세요.
