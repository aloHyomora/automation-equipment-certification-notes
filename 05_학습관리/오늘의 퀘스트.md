# 오늘의 학습 퀘스트

[학습 대시보드의 열기·고정 안내](학습%20대시보드.md#task-genius-화면-열고-고정하기)에서 Task Genius를 연 후 왼쪽의 **Today**를 누릅니다.

## 매일 할 일

1. **Today**에 오늘 날짜의 퀘스트가 자동으로 표시됩니다. 출근·퇴근 미니 강의는 각각 읽고 체크하세요. 본 학습은 보통 1~2개이며, 해당 단원의 회상이나 문제 풀이까지 마친 뒤 체크합니다.
2. 어제까지 완료하지 못한 항목은 원래 날짜를 유지한 채 **Forecast → Past Due**에 남습니다. 완료하면 대기 목록에서 빠집니다. 전체 진도는 단원 및 기출분석 항목을 완료할 때 올라갑니다.
3. 이월이 쌓이면 필수 기출을 먼저 보고, 나머지는 가장 오래된 항목부터 하나씩 합니다. 여유가 있을 때 같은 날 계획 항목도 끝냅니다.
4. 집중 시간을 재려면 Forecast의 퀘스트 원본인 [단원 진도](단원%20진도.md)를 라이브 프리뷰로 열고 해당 줄의 **Start Task → Complete**를 사용합니다.

## 시험까지의 일정

| 기간 | 목표 |
| --- | --- |
| 11월 24일~12월 27일 | 필수 기출분석 3개와 단원 48개를 모두 학습합니다. 과목별 기존 노트 순서를 따르되, 기존 퀘스트의 세 주제는 첫 주에 배치했습니다. |
| 12월 28~31일 | 새 단원 배정을 비워둔 보충 기간입니다. 출퇴근 미니 강의는 기출 복습으로 배정했습니다. Past Due를 비우고, 특히 필수 기출분석이 3/3인지 확인합니다. |
| 1월 1일~시험 직전 | 기출 오답, 빈출 주제 회상, 실전 시간에 맞춘 문제 풀이에 집중합니다. |

Forecast를 계속 열어둔 채 날짜가 바뀌면 앱에 다시 초점을 주거나 Forecast를 다시 열어 오늘 날짜를 반영합니다.
