# 학습 기록

[학습 대시보드](학습%20대시보드.md)

## 오늘 기록하기

1. [단원 진도](단원%20진도.md)를 **라이브 프리뷰**로 열고 학습을 시작할 때 **Start Task**를 누릅니다. 중간에 **Pause**와 **Resume**, 끝날 때 **Complete**를 사용합니다. **Complete**는 시간을 퀘스트 줄에 적고 체크를 완료합니다. 시간을 직접 쟀다면 아래 표에 분 단위로 적습니다.
2. 퀘스트 완료 한 개마다 **10 XP**를 받습니다. 일일 XP 카드는 30 XP를 목표로 표시하며, 이월을 정리해 3개 넘게 완료한 날에도 실제 XP를 기록합니다. 같은 퀘스트를 다시 체크해도 XP는 한 번만 적습니다. 새로운 날의 XP를 전날 누계에 더해 아래 표에 한 행으로 기록합니다.
3. 명령 팔레트에서 **Open Task Genius view**를 열고 **Habit**의 **학습한 날**을 체크합니다. 목표는 퀘스트 한 개 이상 또는 집중 학습 10분입니다. 달력에서 연달아 칠해진 날을 확인합니다. Obsidian의 **오늘의 일일 노트 열기**로 열린 노트에서 숫자 속성 study-xp에 해당 날짜의 XP를 입력하면 **일일 학습 XP** 카드에도 반영됩니다.
4. Forecast에서 **핵심** 및 **필수 기출** 항목을 완료하면 Task Genius가 짧은 휴식 보상을 알립니다. 날짜가 지나도 미완료 퀘스트는 Past Due에 남습니다.

| 누적 50 XP 첫 도달 | 20분 자유시간 |

## 단원 상태

라이브 프리뷰의 상태 전환 순서는 [ ] 미학습 → [/] 학습 중 → [x] 학습 완료입니다. 진도 분자는 완료된 단원 수입니다. 단원 노트를 추가하면 [단원 진도](단원%20진도.md)의 해당 과목에 링크가 있는 체크 한 줄을 추가하세요.
