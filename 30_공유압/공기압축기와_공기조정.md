# 공기압축기와 공기조정

> [!summary] 핵심 요약
> - 압축 공기 계통: **압축기 → 애프터쿨러 → 공기 탱크 → 에어 드라이어 → 메인 배관 → 서비스 유닛(FRL) → 밸브 → 액추에이터**.
> - 압축기 종류: **왕복형**(피스톤·다이어프램), **회전형**(베인·스크루), **터보형**(원심·축류).
> - 에어 드라이어: **냉동식**(이슬점 약 2~10 ℃, 일반 공장), **흡착식**(이슬점 −20 ℃ 이하, 정밀·저온).
> - 서비스 유닛 순서: **필터(F) → 레귤레이터(R) → 루브리케이터(L)**.

> [!warning] 자주 틀리는 포인트
> - **공기 탱크 역할**: 압력 맥동 완화, 공기 저장(순간 대량 소비 대응), 수분 분리(냉각), 압축기 기동 횟수 감소.
> - 메인 배관은 드레인이 모이도록 **1/100 정도 하향 구배**, 분기는 배관 **위쪽**에서 뽑는다(물이 따라가지 않게).
> - 레귤레이터는 **1차 압력이 변해도 2차 압력을 일정**하게 유지한다. 2차 압력은 1차보다 높게 할 수 없다.
> - 다이어프램 압축기는 **오일 프리**(식품·의약). 스크루 압축기는 **맥동이 적고 연속 토출**.
> - **회전형 압축기**: 베인·스크루·스크롤(·루츠). **다이어프램은 왕복형**이다 → "회전형이 아닌 것"으로 출제.
> - **어큐뮬레이터(축압기)는 유압 기기**다. 공압 장치에서 같은 역할은 **공기 탱크**. "공압 구성기기가 아닌 것"의 정답 단골.
> - 공압 **실린더는 압축 공기를 쓰는 쪽(액추에이터)** 이지 압축 공기 **생성** 요소가 아니다.
> - 서비스 유닛은 이물 제거·압력 조절·윤활유 혼합까지만 한다. **진공 발생은 이젝터**의 일.

## 개념 정리

### 압축기 종류

| 분류 | 종류 | 특징 |
| --- | --- | --- |
| 왕복형 | 피스톤 | 고압 가능, 맥동·소음 큼, 소~중용량 |
| 왕복형 | 다이어프램 | 오일 없음, 깨끗한 공기, 소용량 |
| 회전형 | 베인 | 맥동 적음, 소음 적음 |
| 회전형 | 스크루 | 연속 토출, 진동 적음, 공장 주력 |
| 회전형 | 루츠 블로워 | 저압 대풍량 |
| 터보형 | 원심·축류 | 대용량, 저압 |

- 압축기 용량 제어: **ON/OFF 제어**(소형), **언로드 제어**(운전은 계속, 토출만 멈춤), 회전수(인버터) 제어.
- 압축기 설치: 서늘하고 먼지 적은 곳, 흡입 필터 청결, 환기.

### 압축 공기 정화

| 기기 | 역할 |
| --- | --- |
| 애프터쿨러 | 압축으로 뜨거워진 공기를 냉각 → 수분 응축 제거 (수냉·공랭) |
| 공기 탱크 | 저장·맥동 흡수·응축수 분리 |
| 에어 드라이어 | 이슬점을 낮춰 수분 제거 |
| 메인 라인 필터 | 먼지·오일 미스트 제거 |
| 자동 드레인 | 응축수 자동 배출 |

**에어 드라이어 종류**

| 방식 | 원리 | 이슬점 |
| --- | --- | --- |
| 냉동식 | 냉동기로 냉각 → 응축 | 약 2~10 ℃ |
| 흡착식 | 실리카겔·알루미나에 흡착, 재생 | −20 ~ −70 ℃ |
| 흡수식 (조해식) | 화학 약품이 수분 흡수 | 약품 소모 |
| 멤브레인식 | 막으로 수증기 분리 | 소용량 |

### 서비스 유닛 (FRL)

| 기기 | 기능 | 관리 |
| --- | --- | --- |
| 공기 필터 | 먼지·물방울 제거 (원심 분리 + 필터 엘리먼트, 5~40 μm) | 드레인 배출, 엘리먼트 교체 |
| 압력 조절 밸브 (레귤레이터) | 2차 압력을 일정하게 감압 | 압력계로 확인 |
| 루브리케이터 | 오일을 안개로 섞어 공급 | 무급유 기기에는 사용 안 함, 한번 급유하면 계속 급유 |

- 순서를 바꾸면 안 되는 이유: 필터 없이 레귤레이터에 먼지가 들어가면 고장, 루브리케이터 뒤에 필터가 있으면 오일을 걸러 버림.
- 최근 기기는 **무급유형**이 많아 FR(필터 레귤레이터)만 쓰는 경우가 많다.

### 배관

- 배관 방식: **루프식**(압력 강하 적음, 양방향 공급), 분기식.
- 배관 재료: 강관, 동관, 나일론·우레탄 튜브 (원터치 피팅).
- 압력 강하를 줄이려면 관경을 충분히, 굽힘을 적게.
- 공기 누설은 큰 에너지 낭비 → 정기 점검 (비눗물, 초음파 누설 탐지기).
- **배관 지름을 정할 때 고려하는 것**: 공급 유량(공기 소비량), 배관 길이, 허용 압력 강하, 사용 압력, 교축을 일으키는 부속(밸브·엘보 등) 수, 장래 증설. 배관의 **경사 각도는 관경 결정 요소가 아니다**(드레인 구배는 따로 정함).

### 공기압 발생 회로 기호 읽기

- 회로도에서 압축기 다음 순서는 보통 **냉각기(애프터쿨러) → 공기 탱크 → 드레인 배출구 붙이 필터**. 루브리케이터는 맨 끝(액추에이터 바로 앞 서비스 유닛)에 온다.
- 기호 모양은 [공유압 기호](공유압_기호.md) 참고.

## 체크리스트

- [ ] 압축 공기 계통을 순서대로 말한다
- [ ] 압축기 종류별 특징(스크루, 다이어프램)을 안다
- [ ] 공기 탱크의 역할 4가지를 말한다
- [ ] 냉동식·흡착식 드라이어를 이슬점으로 구분한다
- [ ] FRL 순서와 각 기능을 설명한다
- [ ] 메인 배관 구배와 분기 위치 원칙을 안다
- [ ] 회전형·왕복형 압축기를 구분한다 (다이어프램 = 왕복형)
- [ ] 공압 구성기기 목록에서 유압 전용 기기(어큐뮬레이터)를 골라낸다
- [ ] 서비스 유닛이 하지 않는 일(진공 발생)을 안다
- [ ] 배관 지름 결정 요소를 말한다
