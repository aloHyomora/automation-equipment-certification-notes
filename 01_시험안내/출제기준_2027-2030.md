# 자동화설비산업기사 필기 출제기준 요약 (2027.1.1 ~ 2030.12.31)

> 출처: [큐넷 국가자격 종목별 상세정보 – 자동화설비산업기사](https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=2034) > 출제기준
> 세부 내용은 시험 전에 큐넷 원문으로 다시 확인할 것.

## 시험 개요

| 항목 | 내용 |
| --- | --- |
| 직무분야 | 기계 > 기계장비설비·설치 |
| 검정방법 | 객관식 |
| 문제수 | 60문항 (과목당 20문항) |
| 시험시간 | 1시간 30분 |
| 직무내용 | 기계·기구 메커니즘에 전기·전자 제어기술을 활용해 설비 공정 자동화 장치를 설치·운용·개선·유지보수하고 제어기를 설계 |

## 과목별 주요항목 → 세부항목

### 1과목. 자동제어 (20문항) → [10_자동제어](../10_자동제어/README.md)

- PLC제어특수모듈 프로그램 개발: 제어의 기초이론, PLC 특수 프로그래밍 준비·작성, 시뮬레이션 및 수정보완
- HMI프로그램개발: HMI장치통합운용 (HMI, SCADA)
- 전기전자장치조립: 조립, 기능검사, 안전성 검사
- 센서활용기술: 센서 선정, 회로 구성, 신호, 관리
- 모터 제어: 제어방식 설계, 제어회로 구성, 시험 운전, 유지 보수

### 2과목. 기계요소설계 (20문항) → [20_기계요소설계](../20_기계요소설계/README.md)

- 체결요소설계: 요구기능 파악, 체결요소 선정, 체결요소 설계 (풀림방지, 강도)
- 조립도면작성: 부품규격 확인 (운동용·체결용·제어용 기계요소), 도면 작성 (양식, 투상법)
- 조립도면해독: 치수공차·기하공차, 표면 거칠기·열처리 기호, 가공기호

### 3과목. 공유압 (20문항) → [30_공유압](../30_공유압/README.md)

- 공기압제어: 방식설계 (기초, 압축기, 밸브, 액추에이터), 회로구성, 시험 운전 및 안전
- 유압제어: 방식설계 (기초, 펌프, 밸브, 액추에이터), 회로구성, 시험 운전 및 안전
